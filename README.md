# AI Fluency Final Package

## Overview

This repository is the final submission package for my FlyRank AI Fluency track.

It brings together my work across AI Fluency, backend engineering, agent building, automation, portfolio development, and capstone projects completed throughout the track.

The purpose of this repository is to provide one clear place where a reviewer, mentor, university, or potential employer can explore the work I completed and the evidence for each stage.
